# Zero to Maintainer in 45 Days

Presentation research and a Slidev deck for KubeCon + CloudNativeCon North America 2026.

Start the deck:

    cd deck
    npm run dev

See deck/README.md for build/export commands and current dependency notes. Research, source archives, and contribution data live outside the Slidev application directory.

The GitHub Pages workflow publishes the presentation from `main` without speaker notes. Session transcripts, research notes, and raw contribution data remain local and are excluded from this repository.
